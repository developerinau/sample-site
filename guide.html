새 홈페이지(v2) 관리용 · 기존 홈페이지와는 별개

처음이 가이드를 읽는 방법

지금 우리 홈페이지에는 두 개의 홈페이지가 있다고 생각하면 됩니다:

① 기존 홈페이지 — ksqld.org로 접속하면 보이는, 지금 실제로 쓰고 있는 홈페이지

② 새 홈페이지 (v2) — 새로 디자인한 페이지들. 아직 손님들에게는 주소를 알려주지 않았고, 주소를 아는 사람만 볼 수 있음

이 가이드는 ② 새 홈페이지를 관리하는 방법입니다. 기존 홈페이지는 건드리지 않으니 안심하고 연습해도 됩니다.

새 홈페이지 주소들

페이지주소창에 입력할 주소
홈ksqld.org/v2-home/
한인회 소개ksqld.org/v2-about/
이벤트ksqld.org/v2-events/
소식/공지ksqld.org/v2-news/
회비·기부ksqld.org/v2-donate/
한인회관 대관ksqld.org/v2-hall/
문의ksqld.org/v2-contact/

용어모르는 단어 미리보기

가이드에 나오는 단어들입니다. 먼저 훑어보고, 나올 때마다 돌아와서 보세요.

관리자 화면 (대시보드)홈페이지를 관리하는 "뒤쪽 사무실" 같은 화면. 주소 끝에 /wp-admin을 붙여서 들어감
Elementor (엘리멘터)페이지를 마우스로 클릭해서 고치는 도구. "Elementor로 편집" 버튼을 누르면 이 도구가 열림
위젯페이지를 이루는 레고 블록 하나하나. 글자 블록, 사진 블록, 버튼 블록 등
HTML 위젯우리 새 페이지는 대부분 이 블록 안에 화면이 통째로 들어있음. 글자를 바꾸려면 이 안의 코드에서 한글만 수정
미디어 라이브러리홈페이지의 "사진 창고". 사진을 먼저 여기에 올리고 페이지에서 불러다 씀
갤러리 위젯사진 여러 장을 나란히 보여주는 블록. 후원사 로고 모음이 이것
카테고리글을 분류하는 꼬리표. 공지 글을 쓸 때 꼬리표만 붙이면 홈페이지에 자동으로 나타남
게시판 글(Posts)공지사항·소식 같은 글. 페이지 디자인과 상관없이 글만 올리면 됨
업데이트 버튼Elementor 화면 아래의 녹색 버튼. 눌러야 변경사항이 저장됨

01로그인하기

  1. 인터넷 브라우저(크롬, 사파리 등)를 열고 주소창에 ksqld.org/wp-admin 입력 후 엔터
  2. 로그인 화면이 나오면 한인회 아이디와 비밀번호 입력
  3. 로그인되면 검은색 왼쪽 메뉴가 있는 관리자 화면이 나옴 — 여기가 "사무실"입니다
보이는 것: 왼쪽에 세로로 대시보드 · 글 · 미디어 · 페이지 · 댓글 ... 메뉴가 쭉 나열된 화면
비밀번호를 모르면? — "비밀번호를 잊으셨나요?" 링크로 재설정하거나, 관리자 권한이 있는 다른 분께 계정을 만들어달라고 하세요.

02페이지 편집 화면 여는 법 (2가지 방법)

방법 A — 관리자 화면에서 (처음엔 이게 쉬워요)

  1. 관리자 화면 왼쪽 메뉴에서 페이지 클릭
  2. 페이지 목록이 나옴 → 고치고 싶은 페이지 제목 위에 마우스를 올림 (클릭 말고 올리기만)
  3. 제목 아래 작은 글씨로 "Elementor로 편집"이 나타남 → 클릭
  4. 잠시 기다리면 편집 화면이 열림. 왼쪽은 설정판, 오른쪽은 실제 페이지 모습

방법 B — 페이지를 보면서 바로 편집 (더 빠름)

  1. 로그인한 상태에서 주소창에 페이지 주소 입력 (예: ksqld.org/v2-home/)
  2. 화면 맨 위 검은색 얇은 관리자 바가 보임 → 거기서 "Elementor로 편집" 클릭

수정하고 저장하기

  1. 페이지에서 고치고 싶은 부분을 클릭 → 왼쪽 설정판이 그 부분의 설정으로 바뀜
  2. 설정판에서 내용 수정
  3. 화면 아래쪽의 녹색 "업데이트" 버튼 클릭 → 저장 완료
  4. 저장 버튼 옆 눈 아이콘을 누르면 저장 전 미리보기 가능
실수해도 괜찮아요
· Ctrl+Z — 방금 한 작업 취소
· 하단 연필 아이콘 → 개정 이력 — 예전 버전으로 되돌리기
· 저장 안 하고 창 닫으면 — 아무 일도 안 일어남

페이지 안의 글자는 어떻게 바꾸나

새 페이지는 대부분 HTML 위젯 안에 화면이 들어있습니다:

  1. 고치고 싶은 문구가 있는 부분을 클릭 → 왼쪽에 긴 코드 입력칸이 나옴
  2. 입력칸 안을 클릭하고 Ctrl+F (맥은 ⌘+F) → 바꿀 한글 단어 검색
  3. 찾은 글자를 새 글자로 수정
  4. 업데이트 클릭
중요 — 코드에서 <div>, class="..." 같이 꺾쇠괄호와 영어로 된 부분은 건드리지 마세요. 한글로 보이는 문구만 바꾸면 됩니다.

03한/영 텍스트 — 세 곳을 같이 고쳐야 해요

우리 페이지에는 오른쪽 위에 한국어/English 전환 버튼이 있습니다. 그래서 글자 하나가 실제로는 세 군데에 적혀 있어요:

<h1 data-ko="퀸즐랜드 주 한인회가 여러분과 함께합니다"
    data-en="The Korean Society of Queensland">퀸즐랜드 주 한인회가 여러분과 함께합니다</h1>

문구를 바꿀 때는 세 곳 모두 수정해야 합니다:

  1. data-ko="..." 따옴표 안의 한국어
  2. data-en="..." 따옴표 안의 영어
  3. 맨 뒤에 보이는 실제 문구 (>여기</h1> 사이)
하나만 바꾸면 언어 버튼을 눌렀을 때 옛날 문구가 나옵니다. 영어가 아직 없는 부분은 data-ko와 보이는 문구만 바꾸면 됩니다.

04후원사 로고 바꾸기

홈 아래쪽의 후원사 로고들입니다. 큰 카드 3개(주요 후원사)와 작은 로고 모음(일반 후원사)으로 나뉘어 있어요.

작은 로고 모음 — 추가·삭제·순서 바꾸기

  1. 새 로고 파일이 있으면 먼저 미디어 라이브러리에 올립니다: 왼쪽 메뉴 미디어 → 새로 추가 → 파일 끌어다 놓기
  2. v2-home 페이지를 Elementor로 편집 (§02)
  3. 아래로 스크롤해서 후원사 로고들이 나란히 있는 곳을 클릭
  4. 왼쪽 설정판에 "기본 갤러리 편집"이 나옴 → 거기서 로고 썸네일들이 보이는 칸 클릭
  5. 사진 선택 화면이 열림:
    · 추가 — 왼쪽 위 "갤러리에 추가" 누르고 로고 선택
    · 삭제 — 썸네일 위의 X 표시 클릭
    · 순서 — 썸네일을 드래그해서 옮기기
  6. 오른쪽 아래 새 갤러리 생성/삽입 버튼으로 확정 → 업데이트

큰 카드 3개 (주요 후원사)

  1. 바꿀 카드를 클릭 → 왼쪽에 이미지 상자 편집 패널이 나옴
  2. 이미지 칸 → 로고 교체 / 제목 칸 → 후원사 이름 / 링크 칸 → 후원사 홈페이지 주소
  3. 업데이트
로고 파일 팁 — 흰 배경의 PNG가 제일 깔끔합니다. 카드가 흰색이라, 배경이 있는 사진 파일은 테두리가 보여 어색해요. 카드 디자인(흰 배경, 마우스 올리면 컬러로 변하는 효과)은 자동이라 따로 손댈 필요 없습니다.

05홈 맨 위 큰 사진(히어로) 바꾸기

  1. 사진을 먼저 올립니다: 왼쪽 메뉴 미디어 → 새로 추가 → 파일 업로드
    가로가 긴 사진, 가로 1600px 이상 권장
  2. 방금 올린 사진을 클릭 → 오른쪽 정보창의 파일 URL을 복사 (Ctrl+C)
  3. v2-home을 Elementor로 편집 → 맨 위 큰 사진 부분 클릭
  4. 왼쪽 코드 입력칸에서 Ctrl+F로 background-image:url( 검색
  5. url('...') 따옴표 안의 긴 주소를 지우고, 복사한 주소를 붙여넣기
  6. 업데이트 → 눈 아이콘으로 미리보기
사진 위에 어두운 막이 씌워져서 글자가 잘 보이게 돼 있습니다. 밝고 선명한 사진이 잘 어울리고, 너무 어둡거나 인물 얼굴이 정중앙에 크게 있는 사진은 글자와 겹칠 수 있어요.

06공지사항·소식 글 올리기

이건 Elementor를 전혀 열 필요 없는 제일 쉬운 작업입니다. 글만 쓰면 홈페이지에 자동으로 나타나요.

글 작성→ 카테고리 선택→ 공개→ 홈페이지에 자동 표시
  1. 관리자 화면 왼쪽 메뉴 글 → 새 글 추가
  2. 제목과 내용 작성 (워드 쓰듯이)
  3. 오른쪽 카테고리 목록에서 체크:
    · 한인회 소식 → 홈의 공지 목록과 소식 페이지에 표시
    · 대외보도 → 언론에 보도된 기사류
  4. 오른쪽 위 공개 버튼 클릭 → 끝!
수정·삭제도 글 메뉴에서 합니다. Elementor는 안 열어도 됩니다.

07행사 등록하기

"다가오는 행사" 카드는 이벤트 전용 메뉴가 따로 있습니다.

  1. 관리자 화면 왼쪽 메뉴에서 이벤트(Event Listings) 클릭
  2. 이벤트 추가(Add New) 버튼
  3. 행사 이름, 날짜·시간, 장소, 설명, 대표 사진 입력
  4. 공개 → 홈의 행사 카드와 이벤트 페이지에 자동으로 나타남

08한인회관 대관 페이지

대관 신청이 오면 어디로 오나

신청서가 제출되면 두 군데에 기록됩니다:

  1. 이메일 — 폼에 설정된 주소로 알림 메일이 감 (지금은 테스트 주소 developerinau@gmail.com — 정식 운영 전에 담당자 주소로 바꿔야 함)
  2. 제출 내역 — 관리자 화면 Elementor → 제출된 내역(Submissions)에서도 볼 수 있음. 메일이 안 와도 여기엔 남음

수신 이메일 주소 바꾸기

  1. v2-hall을 Elementor로 편집 → 신청 폼 클릭
  2. 왼쪽 설정판에서 Email 탭 → To 칸의 주소를 담당자 이메일로 변경
  3. 업데이트

대관 일정 달력

페이지 중간의 달력은 한인회 구글 캘린더("대관 일정")를 그대로 보여주는 것입니다.

  1. 담당자가 구글 캘린더 앱이나 calendar.google.com에서 일정을 추가·수정
  2. 홈페이지에 자동으로 반영 — 홈페이지에서는 아무것도 안 해도 됨
주의 — 달력의 일정 제목이 손님들에게도 보입니다. 대관자 이름이나 전화번호를 제목에 쓰지 말고, "대관" "○○동호회" 정도로만 적어주세요.
⚠️ 알려진 문제 — 알림 메일이 안 올 수 있음
지금 홈페이지 서버에서 메일 발송이 불안정한 상태입니다. 신청 폼은 정상 작동하고 내역도 저장되지만, 알림 메일이 도착하지 않을 수 있습니다. 정식 오픈 전에 개발 담당이 메일 설정(SMTP)을 잡아줘야 하는 부분입니다. 그 전까지는 Elementor → 제출된 내역을 주기적으로 확인해주세요.

09문의·기부 정보 바꾸기

문의 페이지의 전화번호·이메일, 기부 페이지의 은행 계좌번호 같은 건 HTML 위젯에서 글자만 바꾸면 됩니다 (§02 방법과 동일):

  1. 해당 페이지를 Elementor로 편집 → 정보가 있는 부분 클릭
  2. 코드 입력칸에서 Ctrl+F로 옛 번호/계좌 검색 → 새 것으로 수정
  3. 업데이트
⚠️ 온라인 카드 결제는 지금 작동하지 않습니다 — 기존 홈페이지의 결제 버튼도 서버 오류로 막혀 있는 상태입니다. 고쳐지기 전까지는 계좌이체 안내만 유효합니다.

10주의사항

· 위젯(블록)을 통째로 지우지 마세요 — 실수했으면 저장 전엔 Ctrl+Z, 저장 후엔 개정 이력으로 복구 가능

· 한/영 둘 다 고치기 (§03)

· "홈으로 지정" 같은 설정은 건드리지 마세요 — 기존 홈페이지 교체는 다 같이 결정한 후에 진행합니다

· 사진은 너무 크지 않게 (가로 2000px 이하면 충분)

· 수정 후엔 휴대폰으로도 한번 보기 — 글자가 길어지면 줄바꿈이 어색할 수 있음

· 수정했는데 안 바뀌어 보이면: 화면 맨 위 검은 관리자 바의 Clear Hosting Cache를 누르고 새로고침
